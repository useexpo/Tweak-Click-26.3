# Tweak Click (26.3 Port)

This is an unofficial port of the [Tweak Click](https://github.com/shane04111/Tweak-Click) mod to Minecraft 26.3 (Fabric).

This entire port was made by AI.

Original mod by [shane04111](https://github.com/shane04111).

## Dependencies

- Fabric Loader
- Fabric API
- MaLiLib
- Tweakeroo

## Building

Requires JDK 25.

```bash
./gradlew :26.3:build
```
